#  Nest Finance Tracker

**Nest** is a manual financial tracking app that helps users reflect on their spending habits by inputting transactions one by one. Unlike apps that connect to your bank, Nest prioritizes security and mindfulness—each entry is intentional.

---

## Philosophy

> _“Manual input encourages reflection.”_

Nest doesn't connect to your bank. It’s built around the idea that the act of manually entering each transaction builds awareness and better habits. It’s budgeting with intention, not automation.

---

##  Features

###  Income & Expense Tracker
- Manual input of transactions
- Running balance calculation
- Daily date display
- Transaction history with timestamps
- Search bar to filter past entries

###  AutoLoops
- Tracks recurring bills (e.g., rent, subscriptions)
- Countdown timer until next billing
- Visual breakdown of company, cost, billing cycle

###  AI Spending Coach (Aiden)
- Conversational assistant for budgeting tips
- Casual, real-time messaging interface
- Suggestions for spending, saving, and financial reflection

###  Fare Float
- Peer-to-peer split system
- PIN-based access
- Create group goals and assign member contributions
- Active split dashboard with dynamic progress bars
- Pay-to-split UI and contribution tracking

### Nest Egg
- Savings goal creation and tracking
- Category selector for common goals 
- Goal confirmation and progress visualization
- “Add money” & “Track goals” overlays

###  Spending Caps
- Set daily, weekly, or monthly caps
- Select category and behavior: Warn, Block, or Allow
- Notification system triggers alerts at 25%, 50%, 75%, 90%, and 100%
- Cap dashboard with animated progress meters
- Trend visualization using Chart.js

---

##  Tech Stack

- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Icons & Fonts:** Font Awesome, Custom CDN fonts
- **Charts:** [Chart.js](https://www.chartjs.org/)
- **No backend required** (in-memory simulation)
